# Squidify

Виджет «Сейчас играет» из Spotify для OBS Studio и для рабочего стола Windows. Вы собираете оформление в редакторе, получаете одну ссылку, вставляете её в OBS. Дизайн потом можно менять, ссылка остаётся прежней.

Сайт: <https://blindsquidheh.github.io/Squidify/>

Squidify бесплатный, исходный код открыт. Это независимый проект: он не связан со Spotify AB, не одобрен и не поддерживается Spotify. Spotify — товарный знак Spotify AB.

## Что понадобится

- Аккаунт **Spotify Premium**. Это требование самого Spotify для приложений-разработчиков, обойти его нельзя.
- Пять минут, чтобы создать своё приложение на сайте Spotify for Developers. Зачем так: Spotify разрешил обычным разработчикам не больше 5 пользователей на одно приложение, поэтому у каждого свой Client ID.
- OBS Studio или Windows (для отдельного окна).

## Быстрый старт

### 1. Регистрация

Откройте сайт, нажмите «Регистрация», введите email и пароль. На почту придёт письмо со ссылкой, перейдите по ней. Если письма нет, посмотрите «Спам».

### 2. Приложение Spotify

Всё то же самое подробно показано на странице «Spotify» внутри сайта, там же есть кнопки копирования нужных значений.

1. Откройте <https://developer.spotify.com/dashboard> и войдите своим аккаунтом Spotify.
2. Нажмите **Create app**. Название и описание любые.
3. В поле **Redirect URIs** вставьте адрес со страницы «Spotify» на сайте (скопируйте кнопкой, он должен совпасть до последнего символа, включая `/` в конце) и нажмите **Add**.
4. В вопросе про API отметьте **Web API**, согласитесь с условиями, сохраните.
5. Откройте **Settings → User Management** и добавьте свой аккаунт Spotify (имя и email). Без этого Spotify отвечает ошибкой 403.
6. Скопируйте **Client ID** (Client Secret не нужен) и вставьте на странице «Spotify» на сайте. Нажмите «Подключить Spotify» и разрешите доступ. Squidify просит только одно разрешение: видеть, что вы сейчас слушаете.

### 3. Оформление

В разделе «Мои виджеты» нажмите «Новый виджет». Выберите пресет и подправьте под себя. Предпросмотр рядом работает и без подключённого Spotify: он показывает демонстрационный трек.

### 4. OBS

1. Скопируйте ссылку под предпросмотром («Ссылка для OBS Browser Source»).
2. В OBS: **Источники → + → Браузер**. В поле **URL** вставьте ссылку.
3. Поставьте ширину и высоту, которые рекомендует редактор (они написаны под ссылкой).
4. Фон делать прозрачным вручную не нужно, он уже прозрачный. Не вставляйте свой CSS.

Если после изменения дизайна в OBS ничего не поменялось, правый клик на источнике → **Обновить кэш браузера**.

Ссылка работает как пароль: любой, у кого она есть, видит только ваш виджет, но не аккаунт. Если ссылка попала не туда, нажмите «Новая ссылка» в списке виджетов. Старая сразу перестанет работать, новую придётся вставить в OBS заново.

### 5. Окно Windows (по желанию)

Если нужен виджет поверх игр и программ без OBS, скачайте установщик из раздела [Releases](https://github.com/BlindSquidHeh/Squidify/releases) (файл `desktop-v…`). Windows может предупредить о неизвестном издателе: приложение не подписано платным сертификатом. Нажмите «Подробнее → Выполнить в любом случае».

В списке виджетов на сайте нажмите «В окне Windows». Окно можно двигать мышью, размер меняется за правый нижний угол. Меню в трее: поверх всех окон, зафиксировать положение, пропускать клики. Горячая клавиша по умолчанию `Ctrl+Alt+S`.

## Что умеет редактор

- **Макеты:** горизонтальный, вертикальный, компактный, только текст, крупная обложка, полоса прогресса.
- **Текст:** 21 шрифт, отдельный шрифт для исполнителя, эффекты (градиент, бегущая радуга, неон, контур), своя подпись над названием, прокрутка длинных названий.
- **Визуализатор** вместо полосы прогресса: столбики, зеркальные столбики, волна, точки, эквалайзер и «волна трека» как в SoundCloud. Это анимация, а не настоящий спектр: Spotify не отдаёт приложениям звук трека. Она движется, пока трек играет, и затихает на паузе.
- **Картинки и GIF:** два слота, в любом месте карточки, без фона (если у GIF прозрачный фон). Нужна **прямая ссылка https**. Файл с компьютера вида `C:\Users\...` не подойдёт: OBS открывает страницу из интернета и не видит ваши диски. Загрузите файл на любой хостинг картинок (imgur.com, GIPHY, свой репозиторий GitHub) и вставьте ссылку на сам файл.
- **Фон и рамка:** цвет, градиент (в том числе перетекающий), прозрачность, размытие, тень, пунктирные и двойные рамки, пульсирующее свечение, бегущая радуга.
- **Прогресс:** полоса, линия, свечение, сегменты, точки, бегущие полосы, радуга.
- **Анимации:** девять вариантов смены трека, плюс постоянное парение, пульсация или покачивание.
- **Поведение:** что показывать, когда ничего не играет, и что делать на паузе.
- **Пресеты:** 14 готовых и до 50 своих. До 20 виджетов на аккаунт.

Правила Spotify, которые мы соблюдаем и которые нельзя отключить: рядом с названием всегда стоит значок Spotify (не меньше 21 px), обложку нельзя обрезать, размывать, анимировать и закрывать, скругление обложки не больше 8 px.

## Если что-то не работает

| Что видите | Что делать |
| --- | --- |
| `INVALID_CLIENT: Invalid redirect URI` на странице Spotify | Адрес в Redirect URIs в Spotify не совпадает с адресом на странице «Spotify» сайта. Скопируйте его кнопкой заново, проверьте `/` в конце |
| Виджет пишет про ошибку 403 | Вы не добавили свой аккаунт в User Management приложения Spotify или у владельца приложения нет Premium |
| «Доступ к Spotify истёк» | Доступ отозван на странице spotify.com/account/apps, либо удалён Client ID. Подключите Spotify заново |
| Виджет пустой, хотя музыка играет | Проверьте, что Spotify запущен и трек идёт именно в вашем аккаунте. Обновите кэш источника в OBS |
| В OBS виджет обрезан | Поставьте размер источника, который советует редактор |
| Картинка или GIF не показывается | Нужна прямая ссылка на файл, которая начинается с `https://` и открывается в браузере как сама картинка |
| Не приходит письмо при регистрации | Загляните в «Спам», подождите несколько минут. Письма отправляются через бесплатную почтовую службу с ограничениями |

## Данные и приватность

- Пароль хранится только в защищённом виде у сервиса авторизации Supabase.
- Токен Spotify хранится на сервере в зашифрованном виде и никогда не попадает ни на ваш компьютер, ни в ссылку для OBS.
- Историю прослушивания мы не сохраняем: сервер помнит только текущий трек и перезаписывает его.
- Отключить Spotify можно на странице «Spotify», удалить аккаунт на странице «Аккаунт». Данные удаляются сразу.

Полный текст: страница «Конфиденциальность» на сайте.
